Структура каталогов и файлов

Все страницы сайта хранятся в каталоге `pages/`.

Сайт разделен на разделы. Раздел делится на подразделы. Подраздел так же может делиться на подразделы.

Переход по разделам осуществляется через главное меню сайта. Главное меню сайта отоброжается на любой странице сайта.

Разделы сайта

Сайт разделен на разделы. Имя каждого раздела отображается в главном меню сайта

В структуре каталогов, у каждого раздела свой каталог в pages/

Каталог раздела содержит главную страницу, которая подключается к главному меню сайта.

Страницы раздела

Все страницы раздела находятся в катлоге своего раздела.
